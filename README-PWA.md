# Moo Mee Tang — เวอร์ชันแอปติดตั้งบน iPhone (ใช้งานออฟไลน์ได้)

เวอร์ชันนี้คือแอปตัวเดิม แต่ทำเป็น **PWA** — ติดตั้งลงหน้าจอโฮม iPhone ได้เหมือนแอปจริง
เปิดแล้วเต็มจอ ไม่มีแถบเบราว์เซอร์ และ **บันทึกรายการได้แม้ไม่มีเน็ต** แล้วซิงก์ขึ้น Google Sheet ให้อัตโนมัติเมื่อกลับมามีสัญญาณ

ฐานข้อมูลจริงยังเป็น Google Sheet แผ่นเดิม เปิดดู/แก้ในชีตได้ตลอดเหมือนเดิม

---

## ทำไมต้องเป็น PWA ไม่ใช่แอปจาก App Store

การทำแอปลง App Store ต้องใช้เครื่อง **Mac + Xcode** ในการ compile ซึ่ง Apple บังคับ ไม่มีทางเลี่ยง
PWA จึงเป็นทางที่ทำได้จริงโดยไม่ต้องมี Mac และได้ผลลัพธ์ที่ใกล้เคียงแอปจริงมาก:

| | PWA (วิธีนี้) | แอป Native |
|---|---|---|
| ไอคอนบนหน้าจอโฮม + เปิดเต็มจอ | ได้ | ได้ |
| ใช้งานออฟไลน์ | ได้ | ได้ |
| ต้องมี Mac | **ไม่ต้อง** | ต้องมี |
| ค่าใช้จ่าย | ฟรี | $99/ปี (ถ้าจะขึ้น App Store) |
| แจ้งเตือน Push บน iOS | ได้ (iOS 16.4+) | ได้ |

## ภาพรวม 4 ขั้นตอน

1. **อัปเดต Apps Script** — วางไฟล์ชุดล่าสุด (รวม `Api.gs` ใหม่) สร้างโทเค็นลับ แล้ว Deploy แบบ "ทุกคน"
2. **เอาไฟล์แอปขึ้นเว็บ** — ใช้ GitHub Pages (ฟรี)
3. **ติดตั้งลง iPhone** — เปิดลิงก์ใน Safari แล้ว "เพิ่มไปยังหน้าจอโฮม"
4. **เชื่อมต่อ** — เปิดแอปจากไอคอน แล้ววางลิงก์ + โทเค็นในหน้าเชื่อมต่อ

> ลิงก์และโทเค็น**ไม่ได้ใส่ในไฟล์ใด ๆ บน GitHub** — กรอกในแอปบนมือถือ แล้วเก็บไว้ในเครื่องนั้นเท่านั้น
> เพราะ repo ฟรีบน GitHub เป็นแบบ Public ใครก็เปิดดูไฟล์ได้

---

## ขั้นตอนที่ 1 — อัปเดต Apps Script

### 1.1 วางไฟล์ชุดล่าสุด

1. เปิดสเปรดชีตหมูมีตัง > **ส่วนขยาย > Apps Script**
2. กด **+** ข้าง "ไฟล์" > **Script** ตั้งชื่อ `Api` แล้ววางเนื้อหาจาก `Api.gs`
3. ไฟล์ที่มีอยู่แล้ว ให้ลบของเดิมแล้ววางของใหม่ให้ครบทุกไฟล์ เพื่อให้เป็นเวอร์ชันเดียวกันทั้งชุด:
   `Code`, `Transactions`, `Categories`, `Assets`, `Receipt` (Script) และ `Index`, `Stylesheet`, `JavaScript` (HTML)
4. กด **บันทึก** (Ctrl+S)

### 1.2 สร้างโทเค็นลับ

1. ช่องเลือกฟังก์ชันบนแถบด้านบน — เลือก **`setupApiToken`**
2. กด **เรียกใช้ (Run)** — ถ้า Google ขอสิทธิ์: **ตรวจสอบสิทธิ์ > เลือกบัญชี > ขั้นสูง (Advanced) > ไปที่โปรเจกต์ (ไม่ปลอดภัย) > อนุญาต**
   (คำเตือน "ไม่ปลอดภัย" ขึ้นเพราะเป็นสคริปต์ส่วนตัวที่ Google ไม่ได้ตรวจ ไม่ใช่ไวรัส)
3. ดูที่ **บันทึกการดำเนินการ (Execution log)** ด้านล่าง คัดลอกค่าหลัง `API TOKEN:`

### 1.3 Deploy ใหม่แบบ "ทุกคน"

1. **ทำให้ใช้งานได้ (Deploy) > จัดการการทำให้ใช้งานได้ (Manage deployments)**
2. กดไอคอน **ดินสอ (แก้ไข)** ที่ deployment เดิม
3. **Version:** New version · **Execute as:** ฉัน (Me) · **Who has access:** **ทุกคน (Anyone)**
   ⚠️ ต้องเป็น "ทุกคน" ไม่ใช่ "ทุกคนที่มีบัญชี Google"
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 1.4 ส่งลิงก์ + โทเค็นไปที่มือถือ

ส่งทั้ง 2 ค่าให้ตัวเองทาง LINE (Keep หรือแชตกับตัวเอง) เพื่อเอาไปวางในแอปบน iPhone
**พอเชื่อมต่อสำเร็จแล้ว ให้ลบข้อความนั้นทิ้ง**

> **⚠️ ความปลอดภัย**
>
> ที่ต้องตั้งเป็น "ทุกคน" เพราะแอปอยู่บน GitHub คนละที่กับ Google จึงล็อกอินผ่านบัญชี Google ไม่ได้
> สิ่งที่ยังปกป้องอยู่: สคริปต์รันด้วยสิทธิ์บัญชีคุณ คนอื่นเปิดชีตไม่ได้ และทุกคำขอต้องมีโทเค็น — ไม่มีก็ถูกปฏิเสธ
> โทเค็นอยู่ในมือถือคุณเท่านั้น (ไม่อยู่บน GitHub) ความปลอดภัยของมือถือ (รหัส/Face ID) จึงสำคัญ
>
> **สงสัยว่าโทเค็นหลุด** → รัน `resetApiToken()` แล้วในแอปไปที่ แท็บ "เพิ่มเติม" > **ตัดการเชื่อมต่อ / ใส่โทเค็นใหม่**

## ขั้นตอนที่ 2 — เอาไฟล์แอปขึ้นเว็บด้วย GitHub Pages

PWA ต้องอยู่บนเว็บแบบ **HTTPS** ถึงจะติดตั้งได้ GitHub Pages ฟรีและมี HTTPS ให้อัตโนมัติ

1. แตกไฟล์ `moo-mee-tang-pwa.zip` จะได้โฟลเดอร์ `pwa`
2. สมัคร/เข้าสู่ระบบ [github.com](https://github.com)
3. กด **+** มุมขวาบน > **New repository** ตั้งชื่อ เช่น `moo-mee-tang` เลือก **Public** > **Create repository**
4. กดลิงก์ **uploading an existing file**
5. **เปิดโฟลเดอร์ `pwa` แล้วลากของข้างในทั้งหมดเข้าไป** (ไม่ใช่ลากตัวโฟลเดอร์ `pwa`):
   ```
   index.html  app.js  config.js  style.css
   manifest.json  service-worker.js  icons/
   ```
6. กด **Commit changes**
7. **Settings > Pages** — Source: **Deploy from a branch**, Branch: **main** / **/ (root)** > **Save**
8. รอ 1–2 นาที รีเฟรช จะเห็นลิงก์ `https://ชื่อผู้ใช้.github.io/moo-mee-tang/` — **นี่คือลิงก์แอป**

ไฟล์บน GitHub ไม่มีความลับใด ๆ อยู่เลย ไม่ต้องแก้ไฟล์ไหนเพิ่ม

## ขั้นตอนที่ 3 — ติดตั้งลง iPhone

1. เปิดลิงก์แอปด้วย **Safari** (แนะนำ Safari — ติดตั้งได้เสถียรที่สุด)
2. กดปุ่ม **แชร์** — บน iOS 26 อยู่ในเมนู **⋯** มุมขวาล่าง > **แชร์** (iOS รุ่นเก่าเป็นไอคอนสี่เหลี่ยมมีลูกศรขึ้นตรงกลางล่าง)
3. เลือก **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)** — ถ้าไม่เห็นให้กด "ดูเพิ่มเติม" ก่อน
4. ถ้ามีตัวเลือก **เปิดเป็นเว็บแอป (Open as Web App)** ให้เปิดไว้ > กด **เพิ่ม**

## ขั้นตอนที่ 4 — เชื่อมต่อ (ทำในแอปที่เปิดจากไอคอนเท่านั้น)

1. **ปิด Safari แล้วเปิดแอปจากไอคอนเหรียญบาทบนหน้าจอโฮม**
   (iPhone แยกพื้นที่เก็บข้อมูลของแอปบนหน้าจอโฮมออกจาก Safari — ถ้าไปกรอกใน Safari แอปบนหน้าจอโฮมจะไม่เห็น)
2. หน้า **"เชื่อมต่อกับ Google Sheet"** จะขึ้นมา — วาง **ลิงก์ /exec** และ **โทเค็น** ที่ส่งมาทาง LINE
3. กด **ทดสอบและเชื่อมต่อ** — ถ้าสำเร็จแอปจะเปิดพร้อมข้อมูลจากชีต
4. **ลบข้อความ LINE ที่มีโทเค็นทิ้ง**

ถ้าเชื่อมต่อไม่ผ่าน แอปจะบอกสาเหตุ เช่น
- "ได้หน้าเว็บกลับมาแทนข้อมูล" → Deploy ยังไม่ได้ตั้งเป็น **ทุกคน (Anyone)**
- "โทเค็นไม่ถูกต้อง" → คัดลอกโทเค็นไม่ครบ หรือรัน `resetApiToken()` ไปแล้ว
- "ลิงก์ทดสอบ (/dev)" → ต้องใช้ลิงก์ที่ลงท้ายด้วย `/exec`

**ทดสอบออฟไลน์:** เปิดโหมดเครื่องบิน แล้วบันทึกรายการ — จะขึ้นป้าย **"รอซิงก์"** ปิดโหมดเครื่องบินแล้วแอปจะส่งขึ้นชีตให้เอง

## การใช้งานประจำวัน

- **บันทึกรายการ** — กดปุ่ม **+** เหมือนเดิม ใช้ได้ทั้งออนไลน์และออฟไลน์
- **ดูสถานะซิงก์** — ข้อความใต้ชื่อแอปด้านบนบอกตลอดว่าออนไลน์/ออฟไลน์ และมีกี่รายการรอซิงก์
- **สั่งซิงก์เอง** — กดปุ่ม **⟳** มุมขวาบน (หรือปุ่มในแท็บ "เพิ่มเติม")
- **ซิงก์อัตโนมัติ** เกิดขึ้นเมื่อ: เปิดแอป, กลับมามีเน็ต, สลับกลับเข้าแอป, และหลังบันทึกรายการทุกครั้ง

---

## ข้อจำกัดที่ควรรู้

| เรื่อง | รายละเอียด |
|---|---|
| **ดูเดือนเก่าตอนออฟไลน์** | ดูได้เฉพาะเดือนที่เคยโหลดเก็บไว้แล้ว (ค่าเริ่มต้น: เดือนนี้ + ย้อนหลัง 2 เดือน) ปรับเพิ่มได้ที่ `MONTHS_TO_CACHE` ใน `config.js` |
| **ลบรายการที่ยังรอซิงก์** | ทำไม่ได้จนกว่าจะซิงก์ขึ้นชีตก่อน (เพราะยังไม่มีเลขแถวในชีตให้อ้างอิง) |
| **ถ่ายรูปใบเสร็จ** | ต้องมีเน็ต เพราะต้องส่งรูปไปให้ Google อ่าน |
| **แก้ไขในชีตโดยตรงระหว่างออฟไลน์** | ถ้าแก้/ลบแถวในชีตเองตอนที่มือถือยังออฟไลน์อยู่ เลขแถวอาจขยับ ทำให้คำสั่งลบที่ค้างในคิวลบผิดแถวได้ — เลี่ยงได้โดยกดซิงก์ให้เรียบร้อยก่อนไปแก้ในชีต |
| **ข้อมูลในเครื่องถูกล้าง** | ไม่ต้องกังวล — ชีตคือฐานข้อมูลจริง แค่เปิดแอปตอนมีเน็ตก็ดึงกลับมาครบ (ยกเว้นรายการที่ยังไม่ได้ซิงก์) |

## อัปเดตแอปในอนาคต

แก้ไฟล์ใน GitHub ได้เลย แล้ว **เพิ่มเลขเวอร์ชันใน `service-worker.js`** บรรทัด:
```js
const CACHE_NAME = 'moo-mee-tang-v1';   // เปลี่ยนเป็น v2, v3, ...
```
ถ้าไม่เปลี่ยนเลขนี้ เครื่องจะยังใช้ไฟล์เก่าที่เก็บไว้ ไม่โหลดของใหม่

## แก้ปัญหาเบื้องต้น

**เปิดแอปแล้วขึ้นหน้า "เชื่อมต่อกับ Google Sheet" ทุกครั้ง**
→ อาจกรอกไว้ใน Safari แทนแอปบนหน้าจอโฮม — ให้เปิดจากไอคอนแล้วกรอกในนั้น

**ขึ้น "ซิงก์ไม่สำเร็จ"**
→ เช็ค 3 อย่าง: (1) Deploy แบบ **ทุกคน (Anyone)** แล้วหรือยัง (2) เคยรัน `resetApiToken()` หรือเปล่า — ถ้าใช่ให้กด "ตัดการเชื่อมต่อ / ใส่โทเค็นใหม่" ในแท็บเพิ่มเติม (3) ลิงก์ลงท้ายด้วย `/exec` ไหม

**ข้อมูลไม่ตรงกับในชีต**
→ กดปุ่ม ⟳ เพื่อบังคับซิงก์ ระบบจะดึงข้อมูลจริงจากชีตมาทับเสมอ

**อยากดูรายละเอียดข้อผิดพลาด**
→ แท็บ "เพิ่มเติม" > หัวข้อ "การซิงก์ข้อมูล" จะบอกสถานะและข้อความผิดพลาดล่าสุด
